# HSTU Lab Report Cover Generator

A simple web-based tool to generate A4 cover pages for lab reports, assignments, and other academic documents at Hajee Mohammad Danesh Science & Technology University (HSTU), Dinajpur.

## Features

- 3 cover page templates: Classic, Thesis Styled, and Circuit Tech
- Auto-saves form data in browser localStorage
- Print / Save PDF via native browser print dialog (exact match with preview)
- Responsive design with fullscreen preview modal
- Supports all HSTU faculties and departments

## Usage

1. Open `index.html` in any modern browser
2. Fill in student, teacher, and course details
3. Click **Generate Covers**
4. Preview or Print / Save as PDF

## Templates

| Template | Style |
|----------|-------|
| Classic Report Cover | Traditional bordered layout |
| Thesis Styled Cover | Formal double-bordered design |
| PMF's Style | Modern circuit-board themed |

## Requirements

No build step or server needed. Just a browser with internet access (for Google Fonts).
